# D On Net · ระบบใหม่

SalePro, PurchasePro และ Tech ใช้ฐานข้อมูล Google Sheets ร่วมกัน รันบน Google Apps Script และเก็บ source ใน GitHub

**สถานะ: รุ่น 0.2 โค้ดพร้อมติดตั้งทดสอบ เริ่มข้อมูลธุรกิจใหม่ ผ่านการทดสอบอัตโนมัติ 31 กรณี ยังไม่ได้ deploy หรือทดสอบบัญชี Google จริง ตามที่ขอให้ทำโค้ดให้เสร็จก่อน**

ตามที่ยืนยัน: เริ่มข้อมูลใหม่ทั้งหมด ไม่ดึงข้อมูล/ไฟล์เก่าจาก SharePoint และไม่แก้โฟลเดอร์ระบบเดิม

Repository: https://github.com/Darmmunginsa/DONNET

## ทดลองบนเครื่อง

ต้องมี Node.js 20 ขึ้นไป ไม่ต้อง npm install (ไม่มี runtime dependency)

```powershell
git clone https://github.com/Darmmunginsa/DONNET.git
cd DONNET
npm start
```

เปิด http://127.0.0.1:4173 เลือกบทบาททดลอง ผู้ใช้จำลองใช้โดเมน example.test ไม่ส่งอีเมลจริง ข้อมูลธุรกิจเริ่มว่าง บันทึกเฉพาะไฟล์ .preview-data.json และ .preview-files.json ซึ่งไม่เข้า Git

อย่านำ preview server ขึ้นโฮสต์ภายนอก: มีตัวเลือกสลับบทบาทสำหรับทดสอบ และผูกเฉพาะ 127.0.0.1 ชุด deploy ไม่มี server นี้

## สิ่งที่ทำงานได้ในรุ่นนี้

- กฎอนุมัติตามวงเงินและเหตุผลขายต่ำกว่าทุน, Forecast และกำไรที่เชื่อมต้นทุนรายสินค้า
- คัดลอก/แก้ไขฉบับใหม่/ยกเลิก/เปิดงานใหม่, คืนสินค้าและคืนเงินโดยเก็บประวัติ
- เงื่อนไขส่วนลด VAT เครดิต มัดจำ PO และภาษีหัก ณ ที่จ่าย
- ทะเบียนเอกสารพร้อม snapshot, สำเนาสี, โลโก้/ลายเซ็น/ตราประทับ และส่งออก CSV
- คิวอีเมลอนุมัติ/งานช่าง/RFQ, แจ้งเตือนสัญญา/ครบกำหนดจ่าย และสำรอง Sheet/ไฟล์แนบ (เปิดใช้หลังติดตั้ง trigger)

- ข้อมูลลูกค้า สินค้า ผู้ขาย บริษัท ผู้ใช้หลายบทบาท พร้อมเปิด/ปิดใช้งาน
- ใบเสนอราคา snapshot ข้อมูลลูกค้า/บริษัท คำนวณส่วนลด VAT รองรับหัวข้อ/หมายเหตุ/เว้นบรรทัด/ขึ้นหน้าใหม่
- ส่งอนุมัติ เลือกผู้อนุมัติ เก็บผลและเหตุผล ป้องกันอนุมัติใบของตัวเอง
- รับเงินหลายครั้ง รวมภาษีหัก ณ ที่จ่ายแบบกรอกจำนวนเงิน ตรวจไม่ให้รับเกิน
- ใบเสนอราคา → หลายงานจัดซื้อ โดยอ้าง quoteItemId และควบคุมจำนวนคงเหลือ
- จัดซื้อภายในโดยไม่ต้องมีใบเสนอราคา
- 8 ขั้นจัดซื้อ บันทึกราคาหลายผู้ขายต่อสินค้า เลือกผู้ขายรายสินค้า และสร้าง PO แยกผู้ขาย
- บันทึกจ่ายเงิน ขนส่ง ตรวจรับบางส่วน/ครบ และแสดงสถานะกลับใน SalePro
- ใบเสนอราคา → หลายงานช่าง ผู้รับผิดชอบอัปเดตสถานะ บันทึกค่าใช้จ่ายและสรุปส่งมอบ
- แนบรูป/PDF ระดับงาน เก็บไฟล์ Drive แบบส่วนตัว ดาวน์โหลดผ่านการตรวจสิทธิ์ server
- สัญญาเชื่อมหลายใบเสนอราคาและรวมยอดรับเงิน แสดงหมดอายุ
- พิมพ์ใบเสนอราคา ใบขอราคา PO ใบส่งสินค้า/แจ้งหนี้ และหลักฐานรับชำระเงิน
- ประวัติการแก้ไข รหัสถาวร ตรวจ version กันเขียนทับ และ requestId กันรายการซ้ำ
- Gmail ส่วนตัว: OTP ทางอีเมล เฉพาะผู้ใช้อยู่ใน allowlist รหัสหมดอายุ 5 นาที session สูงสุด 1 ชั่วโมง (อาจสั้นลงเมื่อ cache ถูกเคลียร์)

## ติดตั้ง Google / GitHub

อ่าน [คู่มือติดตั้ง](docs/SETUP.th.md) ระบบมี setup\_() สร้าง Spreadsheet, แท็บข้อมูล, โฟลเดอร์ไฟล์ และผู้ดูแลเริ่มต้นให้ โดยไม่สร้างรายการธุรกิจจำลอง

```powershell
npm run check
```

จะทดสอบกติกาธุรกิจและ adapter แล้ว build ไฟล์พร้อมติดตั้งลง dist/:

- Domain.gs — schema และกติกาธุรกิจ
- Server.gs — Sheets, สิทธิ์, OTP, ไฟล์ Drive
- Index.html, Styles.html, Client.html — หน้าเว็บ
- appsscript.json — manifest

## ขอบเขตการรับรอง

ทดสอบธุรกิจใน Node และ Apps Script adapter กับ mock Google services ไม่ใช่การทดสอบบัญชี Google จริง ต้องทดสอบ deploy, OTP, ไฟล์, quota, หลายบัญชีพร้อมกัน และเอกสารก่อนเริ่มใช้งานจริง รายการคงค้างระบุใน STATUS.th.md
