# คลังเอกสารบริษัท

เพิ่มเมนู **คลังเอกสารบริษัท** (`#company-library`) แยกจากทะเบียนเอกสารออกเลขของงานขาย/จัดซื้อ

- ผู้ดูแลเพิ่มและแก้ไขรายละเอียด อัปโหลดไฟล์ เก็บเข้าฉบับเก่า และคืนมาใช้งานได้
- ฝ่ายบัญชี (บทบาท finance) ค้นหา เปิดดูรายละเอียด และดาวน์โหลดได้
- ฝ่ายขาย ผู้อนุมัติ จัดซื้อ และช่างที่ไม่มีบทบาท admin/finance ไม่ได้รับข้อมูลหรือไฟล์ ไม่สามารถใช้ลิงก์ตรงหรือ RPC เพื่อดาวน์โหลดได้
- หมวดเริ่มต้น 8 หมวด พร้อมพิมพ์หมวดใหม่เองได้ ค้นหาชื่อเอกสาร เลขที่ หมายเหตุ และชื่อไฟล์
- กรองใช้งาน / ใกล้หมดอายุใน 30 วัน / หมดอายุ / แฟ้มเก่า
- เก็บวันออก วันหมดอายุ เลขที่ และหมายเหตุ แนบไฟล์ใหม่เป็นฉบับล่าสุดโดยรักษาไฟล์ก่อนหน้า
- รองรับ PDF, PNG, JPG, WebP, DOCX, XLSX, PPTX, TXT, CSV ขนาดไม่เกิน 5 MB ต่อไฟล์
- ใช้ไฟล์ส่วนตัวในโฟลเดอร์ Drive เดิม และดาวน์โหลดผ่านการตรวจสิทธิ์ของระบบ ไม่เปิดแชร์ลิงก์สาธารณะ

## การติดตั้ง

รุ่นนี้เพิ่มตาราง `CompanyFiles` โดย `upgrade_()` เก็บ metadata ใน Sheets และใช้ Attachments เดิมเชื่อมไฟล์ ต้อง build และแทน Domain.gs, Server.gs, Client.html, Styles.html พร้อมเพิ่มตารางก่อน deploy รุ่นใหม่ ดูขั้นตอนอัปเกรดและสำรองใน LEGACY-FORMS.th.md

ติดตั้งบน Apps Script production แล้ว — Version 2 วันที่ 28 กันยายน 2026 ใช้ deployment URL เดิม ตรวจโครงสร้างฐานข้อมูลบน Google สำเร็จ และนำ wrapper อัปเกรดออกก่อนเผยแพร่ การทดสอบ upload/download และบทบาทด้านล่างเป็นผลจากระบบในเครื่อง ไม่ใช่ผลทดสอบหลังล็อกอินบน production

## ผลทดสอบ 28 กันยายน 2026

- ชุดรวม `npm run check`: 42 tests ผ่าน และ build ผ่าน
- ทดสอบ upload ไฟล์ข้อความสมมติด้วยผู้ดูแล สำเร็จและแสดงเป็นฉบับล่าสุด
- ทดสอบดาวน์โหลดด้วย finance และเปรียบเทียบ SHA-256 ตรงกับต้นฉบับ
- ทดสอบหน้า finance ไม่มีปุ่มแก้ไข/อัปโหลด และหน้า tech ปฏิเสธลิงก์ตรง
- ทดสอบ server: ปิดข้อมูล/ไฟล์ทุกบทบาทที่ไม่ได้รับสิทธิ์, ป้องกัน stale version, เก็บฉบับก่อนหน้า, archive/restore, ตรวจวันที่, จำกัดชนิดไฟล์

ไม่มีการนำเอกสารธุรกิจจริงเข้าคลังในระหว่างทดสอบ
