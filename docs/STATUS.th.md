# สถานะรุ่น 0.2 — โค้ดพร้อมติดตั้งทดสอบ

ผู้ใช้ยืนยันเริ่มข้อมูลใหม่ ใช้ Gmail ส่วนตัว และให้ทำโค้ดก่อนเชื่อมบัญชีจริง ระบบเดิมทั้งสามโฟลเดอร์ไม่ได้ถูกแก้ไข

## ขอบเขตที่สร้างแล้ว

- SalePro: ใบเสนอราคาหลายชนิดบรรทัด, ส่วนลด/VAT, กฎวงเงิน/ต่ำกว่าทุน, ฉบับแก้ไข, คัดลอก, ยกเลิก/เปิดใหม่, รับเงิน/ปรับยอด/คืนเงิน
- PurchasePro: แบ่งจัดซื้อจากรายการขาย, ซื้อภายในหลายรายการและหมวดทรัพย์สิน, RFQ, เทียบราคาต่อรายการ, PO แยกผู้ขาย, ภาษี/เครดิต/มัดจำ, จ่าย/ส่ง/รับบางส่วน, คืนสินค้า/รับเงินคืน/ยกเลิก
- Tech: มอบหมาย/เปลี่ยนช่าง, รับงาน/ดำเนินการ/ส่งมอบ, ยกเลิก/เปิดใหม่, ค่าใช้จ่ายและไฟล์แนบเชื่อมรายการ
- สัญญาหลายใบเสนอราคา, Forecast ถ่วงน้ำหนัก, กำไรตามต้นทุนสั่งซื้อ/ประมาณการและค่าใช้จ่ายช่าง, CSV ตามสิทธิ์
- ทะเบียนเอกสารมีเลขและ snapshot, สำเนาสี, ภาพบริษัท, ใบเสนอราคา/RFQ/PO/แจ้งหนี้/ใบเสร็จ/แบบใบกำกับภาษี
- Gmail OTP + allowlist, สิทธิ์ server, atomic Sheets batch, version checks, idempotency และ audit
- คิวอีเมลและแจ้งเตือนตามเวลา, สำรอง Sheet/ไฟล์แนบแบบทำต่อเป็นชุด

## ต้องตรวจในบัญชีจริงก่อนเปิดใช้

1. ติดตั้ง Apps Script, Sheet และ Drive ด้วยบัญชีเจ้าของ สร้าง GitHub repository และนำ source ขึ้น
2. ทดสอบ OTP ข้ามบัญชี สิทธิ์ดาวน์โหลดไฟล์ การบันทึกพร้อมกัน และ quota จริง
3. ติดตั้ง trigger แล้วทดสอบอีเมล/สำรอง/กู้คืนด้วยข้อมูลทดสอบ
4. กรอกข้อมูลบริษัท ผู้ใช้ และตรวจแบบเอกสารกับผู้รับผิดชอบบัญชีก่อนออกเอกสารจริง

ยังไม่ได้ทำขั้นตอนเหล่านี้ตามคำขอให้จบโค้ดก่อน ไม่ใช่ผลทดสอบผ่านบน Google จริง

## ข้อจำกัด

- อ่านตารางทั้งชุดและเขียนตารางที่เปลี่ยน เหมาะสำหรับทีมเล็ก ต้องวัดปริมาณข้อมูล/เวลา/quota ก่อนขยาย
- กำไรเป็นประมาณการ ใช้ต้นทุนตั้งต้นกับส่วนที่ยังไม่สั่งซื้อ ไม่ใช่บัญชีแยกประเภทหรือคลังสินค้าเต็มรูปแบบ
- คืนสินค้าเป็นการลดจำนวนซื้อและมูลค่า PO เดิม สินค้าทดแทนให้สร้างงานจัดซื้อใหม่จากจำนวนที่คืน ไม่รับเพิ่มทับใน PO เดิม
- เอกสารสร้างรูปแบบใหม่ ไม่รับรองหน้าตาเหมือนเดิมทุกจุด และไม่มีการเชื่อม e-Tax Invoice
- การรับ/จ่าย/คืนเงินเป็นการบันทึกหลักฐาน ไม่ได้โอนเงินผ่านธนาคาร
- ผลส่งอีเมลไม่แน่นอนจะเป็น uncertain ให้ผู้ดูแลตรวจแล้วค่อยลองใหม่ ป้องกันส่งซ้ำอัตโนมัติ
- สำรองไม่ลบชุดเก่าอัตโนมัติ ผู้ดูแลกำหนดอายุเก็บตามพื้นที่ Drive กู้คืนตามคู่มือ ยังไม่มีปุ่มกู้คืนในเว็บ
- การปรับยอด/คืนเงินไม่แก้เอกสารที่ออกไปแล้ว ต้องจัดการเอกสารแก้ไขทางบัญชีตามวิธีของบริษัท
