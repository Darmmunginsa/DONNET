# ผลตรวจรุ่น 0.2

วันที่ 26 กันยายน 2026

`npm run check` ผ่าน 31 tests และ build Apps Script สำเร็จ

ครอบคลุมเส้นทางขาย→อนุมัติ→จัดซื้อ/ช่าง→รับเงิน→ปิดงาน, จำนวนจัดซื้อแยกใบ, สิทธิ์ช่าง, stale version, retry, OTP, atomic Sheets mock และการป้องกัน formula injection

เพิ่มกรณีทดสอบกฎวงเงิน/ต่ำกว่าทุน, credit/refund รวม withholding, เอกสารออกซ้ำคงเลขเดิม, revision/cancel, คืนสินค้ากับส่วนลดและ VAT ที่มีเศษสตางค์, คืนจำนวนไปสั่งซื้อใหม่, คิวอีเมลไม่ส่งซ้ำ, reminder dedupe และ backup ทำต่อหลังไฟล์ล้มเหลว

ตรวจผ่านเว็บ local preview: เข้าด้วยผู้ดูแล, บันทึกการตั้งค่า, เปิด Forecast/กำไร, สร้างงานซื้อภายในสองรายการและเปิดรายละเอียดพบรายการครบ ตรวจ console ไม่มี error ในการทดสอบนี้ รุ่นก่อนตรวจเส้นทางสร้างลูกค้า/ใบเสนอราคา/อนุมัติ/ส่งจัดซื้อ/มอบหมายช่างไว้ใน VALIDATION.th.md

เป็นการทดสอบ Node และ Google services แบบจำลอง ไม่ได้อ้างว่าทดสอบ deploy, MailApp, Drive, trigger หรือ quota บัญชี Google จริงแล้ว ขั้นตอนนั้นอยู่ใน SETUP.th.md
