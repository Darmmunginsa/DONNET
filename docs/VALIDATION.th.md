## Automated checks

`npm run check` ผ่าน 22 tests และ build สำเร็จ

- คำนวณยอดจาก server, snapshot ลูกค้า, เลขเอกสารตามเดือนในเวลาไทย
- สิทธิ์สร้าง/แก้ไข/อนุมัติ และห้ามอนุมัติใบของตัวเอง
- version conflict และ retry ซ้ำไม่สร้าง record เพิ่ม
- แบ่งจัดซื้อหลายครั้งแต่ไม่เกินจำนวนในใบเสนอราคา และไม่รับรหัสสินค้าจากใบอื่น
- วงจรเต็ม: ใบเสนอราคา → อนุมัติ → จัดซื้อ → ราคาผู้ขาย → PO → รับครบ → งานช่าง → ค่าใช้จ่าย → ส่งมอบ → รับเงิน → ปิดงาน
- ช่างไม่เห็นข้อมูลราคา/ใบเสนอราคา/งานผู้อื่น และไม่แก้งานของคนอื่น
- ยอดเกิน ยอดติดลบ วันที่ผิด และจำนวนเงินเกินความแม่นยำถูกปฏิเสธ
- สัญญาหลายใบเสนอราคา บรรทัดเอกสารพิเศษ ซื้อภายใน และป้องกันถอนสิทธิ์ admin ของตนเอง
- OTP allowlist, ใช้ครั้งเดียว, cooldown, อายุรหัสและจำนวนครั้งที่ใส่ผิด
- Sheets adapter เขียนตารางธุรกิจ AuditLog และ Requests ใน batch เดียว; ข้อความขึ้นต้น = ไม่กลายเป็นสูตร
- จำลอง batch ล้มเหลว ไม่เปลี่ยนข้อมูลหรือ retry marker และคืน lock
- ตรวจ public RPC surface ว่า helper/setup ไม่ถูกเปิดเป็น RPC

Google services ใช้ mock ในการทดสอบเหล่านี้ ไม่ได้ติดต่อบัญชีจริง

## ตรวจหน้าจอด้วย browser

ทดสอบจากหน้าเว็บจริงที่ http://127.0.0.1:4173:

1. เข้าทดลองเป็น admin → เพิ่มลูกค้า → สร้างใบเสนอราคา สินค้า 2 ชิ้น × 1,000 บาท → ยอดรวม VAT 2,140 บาท
2. ส่งอนุมัติ → ออกจากระบบ → เปลี่ยนเป็นผู้อนุมัติ → อนุมัติสำเร็จ
3. กลับเป็น admin → ส่งงานจัดซื้อ → เห็น PR เชื่อมในใบเสนอราคา → มอบหมายงานให้ทีมช่าง
4. ตรวจ Dashboard เห็นใบเสนอราคา 1 งานจัดซื้อ 1 และงานช่าง 1
5. เปลี่ยนเป็นช่าง → เห็นเฉพาะเมนูภาพรวม/Tech → รับงานสำเร็จ สถานะเป็นรับงานแล้ว
6. ตรวจหน้าจอ desktop 1440×900 และมือถือ 390×844 ไม่มี page overflow แนวนอนในหน้ารายละเอียดงานช่าง และไม่พบ browser console error ในรอบตรวจ

เก็บข้อมูลทดสอบ UI ไว้ใน test-results/ ซึ่งถูก ignore จาก Git แล้วคืน local preview เป็นข้อมูลธุรกิจว่าง ชุดติดตั้งจริงไม่มีข้อมูลทดสอบนี้
